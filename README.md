# 📚 BookSpinner
**Spin. Pick. Read.**
BookSpinner is a fun Flutter web app that helps you decide what to read next by randomly selecting a book from your personal library using an interactive spin wheel.

## ✨ Features

* 📚 Manage your personal book collection
* 🎡 Interactive book spin wheel
* 🎲 Randomly select your next book
* 🔍 Browse and explore your books
* 📱 Responsive design
* ☁️ Firebase-powered backend

## 🛠️ Tech Stack

* **Flutter** – Web application
* **Dart** – Application development
* **Firebase** – Backend and database
* **Cloud Firestore** – Book collection storage

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* Flutter SDK
* Dart SDK
* A Firebase project

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/BookSpinner.git
```

Navigate to the project:

```bash
cd BookSpinner
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run -d chrome
```
